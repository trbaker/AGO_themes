Install it

A web page can't restyle another site on its own, so the theme has to run in your browser on arcgis.com. Choose one of these. Each uses the theme you built above.

  1. Show your bookmarks bar (Ctrl+Shift+B, or Cmd+Shift+B on a Mac).
  2. Drag this button onto the bookmarks bar:
    ArcGIS Night
  3. Open any ArcGIS Online page you picked, such as Map Viewer, Scene Viewer or the Gallery, and click the bookmark. Click it again to switch back to light.
Lasts until you load a new page. Map Viewer and Scene Viewer keep the theme while you work, but a full page reload needs another click. Site pages such as Gallery and Groups load fresh when you follow a link, so each one needs a click. Use the extension if you want it on every time.

Built on Calcite tokens
ArcGIS Online is built on Esri's Calcite design system, and Map Viewer already ships Esri's dark palette for its left toolbar. The theme applies that palette, or yours, everywhere by redefining the shared color tokens.

    
Tested on the live app
Checked against the live apps on October 28, 2026. Map Viewer: header, toolbars, Layers, Basemap, Add layer, Properties, time slider, search and popups. Scene Viewer: header, welcome dialog, search, Layers, Basemap, Daylight, slides and Share. Site pages, signed out: Home, Gallery, Groups, a group, Search, an item and a profile. Signed in: Organization (Overview, Members, Licenses, Status dashboard, Reports and Settings > General) and My content. Other signed-in screens use general rules; use Check a page to find anything still light.

    
If Esri changes the app
An ArcGIS Online update can rename classes. Tokens keep working; a few widget rules may need a refresh. Map and scene content and your saved items are never touched.

  


  
ArcGIS Online Theme Generator is an unofficial tool and isn't made or supported by Esri. The themes it makes are named ArcGIS Online Night. ArcGIS, ArcGIS Online, Map Viewer and Scene Viewer are Esri products.
